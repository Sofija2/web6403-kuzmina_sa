### Что реализовано

**Общее для всех страниц:**
- единый хедер с названием сайта, слоганом и навигацией (pill-стиль);
- футер с копирайтом и контактами;
- подключение одной таблицы стилей `style.css`;
- адаптивная вёрстка (media-запрос на 700px);
- тёмная тема с кроваво-бордовым акцентом.

**Главная страница (`index.html`):**
- блок hero-split: текст слева, изображение справа;
- секция «Избранное» — 4 мини-карточки с номерами 01–04;
- блок с цитатой;
- секция «Как это работает» — 3 шага;
- CTA-блок с кнопкой перехода в каталог.

**Каталог (`catalog.html`):**
- 15 карточек персонажей;
- в каждой карточке: имя, источник (игра/аниме/кино), два изображения (персонаж + флакон), таблица нот;
- таблица аромата содержит: верхние/средние/базовые ноты, характер, кому подойдёт.

**Поддержка (`support.html`):**
- форма обратной связи (имя, email, персонаж, сообщение);
- блок с другими способами связи;
- блок FAQ (частые вопросы).

### Технологии

- HTML5 (семантические теги: `header`, `nav`, `main`, `section`, `article`, `figure`, `figcaption`, `footer`);
- CSS3 (Flexbox, Grid, CSS-переменные, `radial-gradient`, `transition`, `box-shadow`, media queries);
- Внешний шрифт через `font-family` fallback (Inter / system-ui).
